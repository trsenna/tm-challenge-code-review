# Testing Weather API

Uma API para gerenciar informações climáticas. Este projeto foi criado como um teste técnico e pode ser melhorado para seguir boas práticas de design de código e arquitetura.

## Descrição do Teste

Um desenvolvedor com pouca experiência começou a criar a API, porém não seguiu boas práticas de design de código e arquitetura.

Usando sua experiência em desenvolvimento de software e padrões de design de código, analise o projeto e aplique melhorias que garantam uma boa manutenibilidade.

Leve em conta que essa API irá crescer bastante, terá muitos contribuidores e precisa estar organizada para facilitar a colaboração e evolução. Sinta-se à vontade para criticar, modificar e melhorar o código.

Realize um Fork do projeto, aplique as melhorias diretamente no seu fork e, em seguida, abra uma Pull Request (PR) no repositório original com as alterações propostas para code review.

## Como Configurar o Projeto

Siga os passos abaixo para clonar o repositório, instalar as dependências e iniciar o servidor local:

```bash
git clone https://github.com/<USUARIO>/tm-challenge-code-review
cd tm-challenge-code-review
yarn install
yarn start:dev
```

Por padrão, a API estará disponível em: http://localhost:3000.
